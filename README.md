# YouTube Clone - Mockup

A responsive HTML/CSS mockup of YouTube's homepage created for educational purposes.

## Features

- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **YouTube-like Layout**: Mimics the structure and appearance of YouTube's homepage
- **Dark Theme**: Matches YouTube's current dark mode design
- **Thai Language Support**: UI elements in Thai language
- **Semantic HTML**: Clean, accessible HTML structure
- **Modern CSS**: Uses CSS Grid, Flexbox, and modern properties

## Structure

- `index.html` - Main HTML file with complete homepage structure
- `styles.css` - Comprehensive CSS styling with responsive design

## Components

### Header
- YouTube logo
- Search bar with voice search button
- User navigation icons
- Responsive hamburger menu

### Sidebar
- Main navigation (Home, Trending, Subscriptions)
- Library section (History, Watch Later, Liked Videos)
- Subscriptions list with placeholder channels
- Collapsible on mobile devices

### Main Content
- Video grid layout
- Video cards with thumbnails, titles, and metadata
- Placeholder content for demonstration
- Responsive grid that adapts to screen size

### Footer
- Simple footer with links and copyright information

## Usage

Simply open `index.html` in a web browser to view the mockup.

## Technical Details

- **HTML5** semantic structure
- **CSS3** with modern features (Grid, Flexbox, Custom Properties)
- **Font Awesome** icons
- **Bootstrap 5** for additional styling support
- Responsive breakpoints for different screen sizes
- Smooth animations and hover effects

## Browser Compatibility

Works in all modern browsers that support CSS Grid and Flexbox.
